# ☁️ AWS Cloud Odyssey

### *Un viaje por arquitecturas AWS de producción*

Bienvenido a **AWS Cloud Odyssey**, una serie técnica en español dedicada al diseño de arquitecturas reales sobre Amazon Web Services.

Aquí no quiero limitarme solamente a explicar qué hace cada servicio. El objetivo es documentar **cómo pienso una arquitectura cuando la llevo a un escenario de producción**: qué requisito intento resolver, qué riesgo estoy aceptando, qué alternativa descartaría, qué impacto puede tener en operación y costos.

## 🧠 Perspectiva desde la experiencia

Cada capítulo separa el patrón de referencia, mi decisión como arquitecto y lo que validaría antes de producción. La intención es que cada arquitectura pueda defenderse en una conversación técnica: no solo mostrar servicios, sino explicar por qué están ahí, qué problema resuelven y qué cambiaría bajo otras condiciones.
